# Minimal Portfolio

Modern minimalist developer portfolio focused on clean typography, responsive layout, and smooth user experience.

## Features

- Responsive design for all screen sizes
- Minimalist UI with typography-focused layout
- Smooth transitions and subtle animations
- Modern dark-themed interface
- Project showcase section
- Optimized structure and performance

## Technologies

- HTML5
- CSS3
- JavaScript

## Sections

- Experience
- Projects
- Certifications
- Skills
- Contact

## Goals

This project was created to present frontend development work in a clean and professional way while keeping the interface lightweight and easy to navigate.
